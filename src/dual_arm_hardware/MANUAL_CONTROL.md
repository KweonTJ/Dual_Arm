# 실기 모터 조작창

```bash
cd /home/ktj/Dual_Arm
./manual_control.sh --connect
```

실제 FTDI 포트에 연결해 10개 모터의 현재 절대각, raw 위치, 전압, 온도,
토크 ON/OFF를 표시합니다. 초기 토크는 OFF입니다. DYNAMIXEL Wizard나 다른
제어창이 포트를 점유하고 있다면 먼저 연결을 해제합니다.

1. 현재각을 확인한 뒤 **전체 토크 ON · 현재 위치 유지**를 누릅니다.
   먼저 실제 현재 위치를 목표로 기록하고 모터를 켭니다.
2. 모터 ID별 슬라이더 또는 목표각 숫자를 조절합니다. 숫자 입력의 위/아래
   버튼은 약 0.293°(1 tick)씩 움직입니다. 이동 속도 보간은 추가하지 않습니다.
3. **현재 위치 유지**는 새로 읽은 현재각을 목표에 다시 맞춥니다.
4. **전체 토크 OFF**는 구동을 끕니다. **긴급 정지**는 토크 OFF를 시도하고
   오류 상태를 유지합니다. 창을 닫아도 전체 OFF와 재조회를 수행합니다.
   토크 OFF 시에는 팔의 지지력이 사라집니다.

표시/목표는 **모터 절대각 0~300°**입니다. URDF의 관절각이나 집게 벌림 mm가
아닙니다. 각 모터에서 읽은 기존 CW/CCW 범위 안에서만 목표를 보냅니다.
이 장치 범위를 기구적으로 간섭 없는 범위로 확인한 것은 아닙니다.
현재 실측 위치가 URDF 범위 밖이어도 다른 모터의 위치를 영점으로 보내지 않고
그대로 유지한 채 선택한 목표만 변경합니다. 모델의 180° 영점과 방향 설정은
변경하지 않습니다.

`configure_protection: false`를 사용하며 CW/CCW·Max Torque·Torque Limit·Shutdown·
Moving Speed를 쓰지 않습니다. 기존 모터 설정을 유지합니다. 통신 오류,
목표값 재조회 실패, UI 갱신 중단은 기존 low-level 정지 경로를 사용합니다.

장치 없는 화면 검사는 `./manual_control.sh --mock --connect`로 실행합니다.
62개 하드웨어/GUI 검사에서 현재 위치 초기화, 비중립 자세의 독립 목표 전달,
기존 장치 범위, 입력 거부와 종료 시 OFF를 확인했습니다. 실제 화면 프리뷰는
`preview/10_실기_모터_조작창.png`, 연결/명령 기록은 `log/manual_control/`입니다.
