# 양팔 디지털 트윈 — 물리 시뮬레이션

현재 URDF를 MuJoCo에 불러와 **중력·관성·접촉·관절 제한·제한된 구동 토크**에 따라 움직이는 초기 시뮬레이션입니다. 슬라이더는 목표각을 지정하고, 3D 로봇과 상태 표는 물리 엔진이 계산한 실제 시뮬레이션 상태를 보여줍니다. 목표값을 모델 위치에 바로 복사하지 않습니다.

```bash
cd /home/ktj/Dual_Arm
./simulation.sh
# 같은 화면을 모니터 진입점에서 실행:
./monitor.sh --sim
```

매번 현재 Xacro와 YAML로 `log/simulation/current.urdf`를 전개한 뒤 물리 모델을 생성하므로 다시 실행하면 모델 변경이 반영됩니다. `display.sh`는 기존 RViz 형상 프리뷰이며, `monitor.sh`의 인자 없는 실행은 실기 진단 토픽용 터미널 모니터입니다. 시뮬레이터는 실제 모터에 연결하거나 명령을 보내지 않습니다.

## 화면 조작

- 왼팔·오른팔 슬라이더/숫자 입력: 12개 목표 관절각을 독립적으로 변경합니다. 각 행에 실제 모터 ID를 표시하고 CSV의 `motor_id` 열에도 기록합니다. 오른팔(정면 왼쪽)은 5·4·3·2·12·1, 왼팔(정면 오른쪽)은 10·9·8·7·13·6입니다(어깨 pitch·roll, 팔꿈치, 손목, 안쪽·바깥쪽 집게 순서).
- 현재각·오차·속도·토크/상한: 물리 계산 결과와 설정된 관절별 상한입니다. 토크는 actuator 출력(N·m)이며 접촉 반력이나 실측 토크 센서 값이 아닙니다.
- `도달`: 오차 0.5° 이내이고 속도 1°/s 이내입니다. `이동 중`과 `토크 제한`을 구분해 표시합니다. 중력이나 접촉 때문에 목표각을 따라가지 못하면 오차가 남습니다.
- `가상 모터 OFF`: 구동 토크가 0이 되어 중력과 접촉에 따라 움직입니다. 다시 ON하면 현재 자세를 목표로 잡습니다.
- 일시정지/계속 실행, 초기화, 영점 목표, 어깨 90°, 팔 굽히기: 모두 가상 환경에만 적용됩니다. `어깨 90°`는 양팔 shoulder pitch에 90°를 명령하고 나머지는 0°로 지정합니다. 초기화는 물리 상태와 가상 물체를 되돌립니다.
- 왼쪽 드래그: 회전, 오른쪽 또는 Shift 드래그: 이동, 휠: 확대/축소. 정면/입체 시점 버튼도 있습니다.
- `충돌 형상`: 접촉 계산에 쓰는 단순화된 URDF collision을 겹쳐 보여줍니다.
- `CSV 기록`: `log/simulation/records/simulation_UTC시각.csv`에 시뮬레이션 시각·목표각·현재각·속도·구동 토크·토크 상한·상한 도달 여부·접촉점 수·모터 활성 상태·추종 오차·중력/코리올리 보상 토크·적분 토크를 약 10Hz로 저장합니다. 기록 중 초기화하면 파일을 닫아 서로 다른 시뮬레이션 시간축을 섞지 않습니다.

검정 파이프와 양팔 형상은 기존 URDF를 사용합니다. 파이프 아래의 회색 기둥/바닥판은 시뮬레이션의 고정 치구이며 실제 로봇 부품으로 추가한 것이 아닙니다. 주황색 25g 블록은 자유 낙하와 바닥 접촉을 확인하는 가상 물체입니다. 로봇 기준부는 월드에 고정됩니다.

## 현재 물리 설정과 한계

| 항목 | 적용 |
|---|---|
| 로봇 형상·질량·관성 | 현재 URDF. 로봇 질량 합계 1.0912kg, 파이프 0.2kg |
| 모터 영점 | 실제 180°에 해당하는 모델 q=0° 유지 |
| 각도 범위 | URDF의 12개 관절 범위, 손목 ±67.5° 포함 |
| 구동 토크 상한 | 아래 관절별 시뮬레이션 설정 사용. URDF `effort` 및 실기 설정을 변경하지 않음 |
| 속도 | 별도 상한/목표각 보간 없음. 물리·제어 토크에 따라 결정 |
| 중력 / 시간 간격 | −9.81m/s² / 0.001초 |
| 서보 | 중력·코리올리 보상 + 관절별 PID + 포화 시 적분 누적 방지 |
| 접촉 | URDF collision과 마찰, 인접 링크 기본 제외. 정밀 CAD 접촉은 아님 |

목표각 입력은 범위 내로 제한합니다. 물리 엔진의 관절 stop은 수치적 제약이므로 작은 오차/일시적인 초과가 생길 수 있습니다. 값 자체를 잘라 위치를 순간이동시키지는 않습니다. 실기 토크 비율(AX-12A register %)을 N·m로 자동 환산하지 않습니다.

### 관절별 제어값

좌우에 동일한 프로파일을 사용합니다. kp는 N·m/rad, kd는 N·m·s/rad, ki는 N·m/(rad·s) 단위입니다.

| 관절 | 출력 상한 N·m | kp | kd | ki | 적분 토크 상한 N·m |
|---|---:|---:|---:|---:|---:|
| 어깨 pitch | 0.75 | 4.0 | 0.40 | 1.5 | 0.06 |
| 어깨 roll | 0.75 | 4.0 | 0.40 | 1.5 | 0.06 |
| 팔꿈치 | 0.40 | 3.0 | 0.20 | 1.0 | 0.04 |
| 손목 | 0.12 | 1.2 | 0.035 | 0.8 | 0.02 |
| 집게 안쪽 | 0.06 | 0.6 | 0.020 | 0.5 | 0.02 |
| 집게 바깥 | 0.06 | 0.6 | 0.020 | 0.5 | 0.02 |

현재 모델의 3,500개 자세 표본에서 최대 중력 토크는 어깨 약 0.51, 팔꿈치 약 0.27, 손목 약 0.007, 집게 약 0.012N·m였습니다. 위 상한은 이 모델에서 목표 추종을 시험하기 위한 **시뮬레이션 가정**이며, AX-12A의 허용 연속 토크나 실기 안전 설정으로 검증한 값이 아닙니다.

제어 순서는 현재 물리 상태 계산 → 중력·코리올리 보상 + PID → 전체 합산 토크 제한 → 물리 적분입니다. 보상 토크를 외력으로 따로 넣어 제한을 우회하지 않습니다. 포화 방향으로 오차가 증가할 때 적분을 멈추고, 반대 방향으로 풀리는 경우만 허용합니다. 목표 변경·모터 OFF/ON·초기화 시 적분 상태를 지웁니다. 모터 OFF일 때 보상도 꺼져 중력에 따라 움직입니다.

기존 공통 0.30N·m 상한과 PD만 사용하면 어깨 목표 90°에서 현재각이 약 33.5°에 머물렀습니다. 변경한 제어의 6초 후 어깨 오차는 약 0.01°, 11개 시험 자세의 최대 오차는 약 0.13°였습니다. 관절 stop의 시험 중 최대 초과는 약 0.14°로, 물리 솔버 오차를 포함한 결과입니다.

**현재는 실측으로 보정되지 않은 물리 시뮬레이션 단계입니다.** 일부 치수·질량중심·관성은 기존 사진 기반 추정치이고, 서보 지연·백래시·마찰 계수도 실측 식별 전입니다. 전압·온도·전류·열화 모델은 없으며 값을 만들어 표시하지 않습니다. 실제 로봇 상태와의 실시간 동기화/양방향 제어는 아직 연결하지 않았습니다. 그 단계에는 실제 통신 어댑터, 포트, baudrate, 배정한 12개 ID의 실제 응답, 회전 방향과 영점 확인이 필요합니다.

엔진 및 관절별 제어 설정은 `config/simulation.yaml`, 변환 결과와 원본 URDF·제어 설정 해시는 `log/simulation/model_manifest.json`에 남깁니다. `src/dual_arm_hardware/config/hardware.yaml`에는 변경을 적용하지 않습니다. 단일 시뮬레이션 프로세스에서 화면과 상태 표를 갱신하므로 ROS DDS 없이도 조작할 수 있습니다.

## 설치와 검증

검증 환경: ROS 2 Humble의 Xacro/description 패키지, Python 3.10, MuJoCo 3.10.0, NumPy, PyYAML, PyQt5, EGL 렌더링. MuJoCo는 현재 사용자의 Python site에 설치되어 있습니다. `requirements.txt`에 검증한 엔진 버전을 기록했습니다.

```bash
source /opt/ros/humble/setup.bash
colcon build --symlink-install --packages-select dual_arm_description dual_arm_simulation
./simulation.sh --headless --seconds 5
/usr/bin/python3 src/dual_arm_simulation/scripts/test_simulation.py -v
/usr/bin/python3 src/dual_arm_simulation/scripts/validate_control.py
# 어깨 90° 추종을 직접 확인:
./simulation.sh --pose shoulders90
# 창 전체 프리뷰 갱신:
./simulation.sh --headless --pose shoulders90 --seconds 6 --screenshot preview/06_디지털_트윈_시뮬레이션.png
```

2026-10-05: 실제 MuJoCo 엔진으로 12개 회귀 검사와 11개 목표 자세 시험을 수행합니다. 회귀 검사는 질량/관절/손목 위치 보존, 목표각 유효성, 토크 포화와 관절 stop, 중력 낙하·바닥 접촉, 모터 OFF, 일시정지·초기화, 물리 오류 처리, 화면 조작·CSV, 설정 유효성, 어깨 90° 유지, 과부하 후 회복, 목표 반전을 포함합니다. 수치 보고서는 `log/simulation/control_validation/control_validation.json`에 저장합니다. 실제 로봇과 수치가 일치한다는 검증은 아닙니다.
